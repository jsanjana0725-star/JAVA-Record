Exception Handling in Java
Exception handling is a mechanism in Java used to handle runtime errors so that the nor-
mal flow of a program can be maintained.
Examples of situations that may cause exceptions:
 Dividing a number by zero
 Accessing an invalid array index
 Using a null object
 Entering invalid data
 Opening a file that does not exist

Java exceptions are mainly classified into:

Examples:
 IOException

Checked Exceptions – How to Handle
Checked exceptions must be handled at compile time. Java provides two main ways:
1. Using try-catch
try {
FileReader f = new FileReader("data.txt");
} catch (FileNotFoundException e) {

void readFile() throws FileNotFoundException {

3. Uncaught Exceptions
If an exception occurs and there is no appropriate catch block to handle it, the exception be-
comes an uncaught exception.
The JVM's default exception handler:
1. Displays the exception name.
2. Displays the error message.
3. Displays the stack trace.
4. Terminates the program.
Example
class Demo {
public static void main(String[] args) {
int a = 10 / 0;
System.out.println("Hello");
}
}
Output:
Exception in thread "main"
java.lang.ArithmeticException: / by zero
The statement:
System.out.println("Hello");
is never executed.

5. Importing Packages
The import statement allows us to use classes from another package without writing their com-
plete package name every time.
Syntax
import package_name.ClassName;
Example
import java.util.Scanner;
public class Demo {
public static void main(String[] args) {
Scanner sc = new Scanner(System.in);
System.out.print("Enter your name: ");
String name = sc.nextLine();
System.out.println("Hello " + name);
}
}
Without import, we could write:
java.util.Scanner sc = new java.util.Scanner(System.in);
Importing all classes from a package
We can use *:
import java.util.*;
Example:
import java.util.*;
public class Demo {

Important
import java.util.*;
imports classes directly inside java.util; it does not import sub-packages.
For example:
import java.util.*;
does not automatically import classes from:
java.util.concurrent

7. Advantages of Packages
1. Organizes classes into logical groups.
2. Avoids naming conflicts between classes.
3. Provides access protection.
4. Makes programs easier to maintain.
5. Allows code reuse.
6. Makes large Java applications easier to manage.
In short
Package
↓
Collection of related classes/interfaces
↓
package keyword → Define package
import keyword → Use classes from package
CLASSPATH → Find packages/classes
Access modifiers → Control package member access
