Lambda Expressions in Java
Definition : Lambda expressions were introduced in Java 8. They provide a sim-
ple and short way to write the implementation of a functional interface.
In Java, a functional interface is an interface that has exactly one abstract
method.
Simple example
@FunctionalInterface
interface Calculator {
int calculate(int a, int b);
}
Calculator is a functional interface because it contains only one abstract
method: calculate().
functional reference contain only one abstract method. The main reason is to
avoid ambiguity when a lambda expression is used.
Example
interface Calculator {
int add(int a, int b);
int subtract(int a, int b);
}
Now:
Calculator c = (a, b) -> a + b;
The problem is that the lambda syntax:
(a, b) -> a + b
does not contain the method name add.
Java sees:
(a, b) -> a + b
↓
int, int → int
Both methods match:

add(int, int) → int
subtract(int, int) → int
So Java cannot say:
"a + b looks like addition, therefore use add()."

Thread Synchronization in Java
1. Definition
Thread synchronization is a mechanism used to control the access of multiple threads to a
shared resource.
When multiple threads access the same data simultaneously, it may lead to data inconsis-
tency. Synchronization ensures that only one thread can access the critical section at a
time.
2. Why is Synchronization Needed?
Consider two threads trying to increment the same variable:
count++;
If both threads execute this statement at the same time, the final value may not be correct.
Synchronization solves this problem by allowing only one thread at a time to execute the
synchronized code.
3. Simple Example
class Counter {
int count = 0;
synchronized void increment() {
count++;
}
}
class MyThread extends Thread {
Counter c;
MyThread(Counter c) {
this.c = c;
}
public void run() {
for (int i = 1; i <= 1000; i++) {
c.increment();
}
}
}

A method can be declared using the synchronized keyword.

// critical section
}
Only one thread can execute this synchronized method on the same object at a time.

5. Synchronized Block

}
